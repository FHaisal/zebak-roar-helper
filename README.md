# Zebak Roar Helper

A RuneLite plugin that provides visual assistance during Zebak's Great Roar attack in the Tombs of Amascut.

## Features

- **Jug Highlighting**: Highlights jugs on the floor, indicating which ones are aligned with rocks.
  - **Optimal Mode**: Highlights the jug that will clear the most rocks.
  - **Nearest Mode**: Highlights the jug closest to the player that clears at least one rock.
  - **All Mode**: Highlights all jugs based on their alignment.
- **Attack Mode**: Detects if a jug's stance tile is covered in acid or if it has no target rocks, highlighting the jug in purple to indicate it should be attacked instead of pushed.
- **Stance & True Tile Indication**: Shows the exact tile you need to stand on to push the jug, and draws the Server True Tile of the jug while it's rolling.
- **Roar Timer**: Adds a flashing UI countdown timer showing how many attacks Zebak will do before the Great Roar.
- **Safe Zone Rendering**: Highlights the safe tiles behind rocks so you know exactly where to stand.

## Configuration

All colors and visual elements are fully customizable in the plugin configuration menu.
